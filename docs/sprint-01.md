# Sprint 1 - Fundamentos do Python

## Objetivo

Aprender os conceitos fundamentais do Python aplicados ao Marketing.

## Conceitos estudados

- Variáveis
- Tipos de dados
  - str
  - int
  - float
  - bool
- print()
- type()
- Conversão com str()
- f-strings
- Formatação de saída

## Aplicação prática

Desenvolvimento de um relatório simples para uma campanha de marketing contendo:

- Nome da campanha
- Plataforma
- Orçamento diário
- Cliques
- Conversões
- Status

## Aprendizados

- O tipo de um dado depende do seu significado, não apenas da sua aparência.
- Um código de produto pode ser uma string.
- f-strings deixam o código mais limpo e legível.
- A apresentação dos dados também faz parte da qualidade do software.
