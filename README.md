# Marketing Data Lab

Laboratório de projetos desenvolvido para aplicar Python na resolução de problemas reais de Marketing Digital e Análise de Dados.

## Objetivos

- Aprender Python de forma prática
- Construir projetos profissionais
- Aplicar programação ao Marketing
- Desenvolver habilidades em Análise de Dados
- Criar um portfólio para o GitHub

## Tecnologias

- Python
- Git
- GitHub
- NumPy
- Pandas
- Matplotlib
- SQL (em breve)
- Power BI (em breve)
